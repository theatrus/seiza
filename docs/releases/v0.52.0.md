# Seiza 0.52.0

Seiza can download the latest published noise model from the hosted model
catalog. `seiza model install` installs the catalog's recommended model, and
`seiza model install NAME` selects a specific published bundle. The installer
verifies the card and graphs and reports download and installation progress.

On a first denoise with no model installed, Seiza checks ONNX Runtime and
downloads the recommended model. Subsequent runs use the installed model and
work offline. To pick up a newer model, run `seiza model install` again or use
the model option in `seiza setup`.

Rust hosts can use `ModelManager` and `ModelStore::download`. The C ABI and
Python expose the same install operation with progress callbacks. The initial
published model is `noise-v1-d33`.

Stacking, stretch, pipeline and model output versions stay the same. This
release adds model distribution and moves the published dependency chain with
the new workspace version.
