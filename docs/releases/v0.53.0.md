# Seiza 0.53.0

Seiza supports DirectML for learned noise models on Windows D3D12 GPUs,
including Intel integrated graphics and Arc. With a DirectML-enabled ONNX
Runtime, automatic backend selection prefers DirectML when the model allows
it. Use `--backend directml --device-id INDEX` to choose a DXGI adapter.
The Windows CLI packages still include the CPU runtime; pass `--onnxruntime`
to use a separately installed DirectML runtime. Seiza for Windows supplies its
own DirectML runtime.

File restoration now lives in the shared Rust library. The CLI, C ABI, and
Python use the same linear FITS/XISF input, bounded center preview, cached
residual blending, shared display stretch, and full-resolution FITS export
with WCS and model provenance. Center previews process at most 768 by 768
pixels. Compressed XISF may need a full decode before cropping.

Hosts can fetch the validated model catalog without downloading model graphs.
The C ABI and Python expose this alongside the new file-restoration operations
and DirectML adapter selection.

Validated DirectML inference on Intel Iris Xe and Arc A770M. CPU full-image
export matched Seiza 0.52.0 byte for byte on the verification image. Stacking,
stretch, pipeline, and model output versions remain unchanged.
