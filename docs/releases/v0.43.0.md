# Seiza 0.43.0 preparation

Unreleased. Keep this work in draft until the complete feature set and reviews
are ready. No merge, release tag, crate publication or wheel publication is
part of this preparation.

## Color processing

- Balance stretched H-alpha/OIII/SII channels against H-alpha while protecting
  backgrounds. Flat or noise-dominated channels report why balancing skipped.
- Recombine RGB stars with a starless narrowband nebula using one shared
  display transfer and a screen-compatible stars layer.
- Fit and subtract broadband continuum on aligned linear narrowband images.
  Use automatic isolated-star aperture photometry, premeasured stellar fluxes,
  explicit manual weights or an exact-source saved plan. Inspect held-out-star
  diagnostics and skip reasons before accepting a result. Signed residuals,
  negative samples and missing coverage are retained.

The Rust core, C ABI, Python package and CLI expose the same operations.
Continuum fitting runs before display balance, stretching or star removal.
LRGB+SHO blending and automatic filter selection remain host policies; these
operations do not claim pure line flux or numerical parity with third-party
PixInsight modules.

## Versions to publish together later

The workspace packages (`seiza`, `seiza-cabi`, `seiza-cli`) and Python package
are prepared as 0.43.0. `seiza-stacking` and its output version are 0.47.0.
`seiza-satellites` 0.22.1 and `seiza-parallax` 0.19.1 carry the compatible
Seiza dependency. Their numerical behavior is unchanged. Stretch output
versions and existing stacking summaries remain unchanged.

The version-chain guard must remain green. PSF Guard's paired draft PR
requires the published versions and a registry-resolved lockfile before it
can pass hosted Rust builds. Local path patches are validation only.
