# Seiza 0.43.0

Seiza 0.43.0 adds narrowband display balance, validated stellar continuum
subtraction and independent RGB star reduction. The Rust core, C ABI, Python
package and CLI expose the same operations.

## Color processing

- Balance stretched H-alpha/OIII/SII channels against H-alpha while protecting
  backgrounds. Optional star masks exclude stars from balance statistics.
  Flat or noise-dominated channels report why balancing skipped.
- Recombine RGB stars with a starless narrowband nebula using one shared
  display transfer and a screen-compatible stars layer. Reduce the restored
  stars independently; zero preserves the existing screen result.
- Reduce excess green before restoring RGB stars, and mix prepared starless
  broadband structures into a narrowband display.
- Fit broadband continuum on aligned linear narrowband images using isolated
  stellar aperture photometry, premeasured fluxes, manual coefficients or an
  exact-source saved plan. Retain signed residuals, negative samples and
  missing coverage when subtracting the fitted continuum.
- Validate automatic fits against held-out stellar pixel profiles and clipped
  cores. Producer clipping maps support inputs whose saturation level is
  unknown. Failed checks report a skip reason. Explicit Gaussian PSF matching
  can broaden inputs to a common resolution; reports record that resolution.
- Project signed emission residuals into broadband RGB units and carry
  calibrated color gains into their contribution.
- Export calibrated line flux only with explicit response matrices, additive
  zero levels, exact sources and continuum coefficient snapshots. Account for
  broadband line leakage and report covariance and uncertainty assumptions.

Continuum fitting runs before display balance, stretching or star removal.
LRGB+SHO blending and automatic filter selection remain host policies. Display
blends do not claim pure line flux or numerical parity with third-party
PixInsight modules. On the tested real fields, clipped cores can still prevent
an automatic fit even when PSF matching improves unsaturated star profiles.

The CLI closes reserved temporary files before writing continuum exports, so
FITS and XISF exports can replace outputs atomically on Windows as well.

## Package and output versions

The workspace packages (`seiza`, `seiza-cabi`, `seiza-cli`) and Python package
are 0.43.0. `seiza-stacking` and its output version are 0.50.0.
`seiza-satellites` 0.22.1 and `seiza-parallax` 0.19.1 carry the compatible
Seiza dependency; their numerical behavior is unchanged.

The stretch output version is unchanged. Existing disabled-mode stacking
summaries remain unchanged. Enabled continuum fixtures now select valid
fainter stars from saturated candidate pools and reject pixel-profile
mismatches. Hosts should use the stacking output version in cache identity.

PSF Guard's combined-color preview support uses these published crates. Its
registry-resolved lockfile replaces the local path patches used during
validation.
