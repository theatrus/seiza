# Seiza 0.44.2

Seiza 0.44.2 prevents RC-Astro tools from opening console windows when called
from a Windows desktop app, tray worker or service
([#378](https://github.com/theatrus/seiza/pull/378)).

## RC-Astro runs without a console window on Windows

Schema probes and tool runs now start with `CREATE_NO_WINDOW`. Previously,
Windows could open a console for each call from an app without a console of
its own, and closing that window stopped the tool. Progress, output and error
messages still pass through the host as before.

The C ABI and Python use the same core implementation. Other platforms keep
their existing process-launch behavior.

## Package and output versions

The workspace packages (`seiza`, `seiza-cabi`, `seiza-cli`) and Python package
are 0.44.2. `seiza-stacking` is 0.51.2. Stacking output stays 0.51.0 and stretch
output stays 0.3.0, so cached stacks and previews remain valid.
