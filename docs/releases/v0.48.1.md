# Seiza 0.48.1

Seiza 0.48.1 adds a calibration setting that lets a flat master another
program integrated at another gain or offset calibrate lights. It covers,
for example, a master built from gain-0 flats and flat darks for gain-100
lights.

## External flat masters at another gain

- **`allow_flat_gain_offset_mismatch`** (**External flat masters at another
  gain**) is a matching toggle in `seiza_calibration::library::rules`, off
  by default, for the whole library or one rig. `Rules::tolerances` hands
  it to the stack's gate. Turning it on changes the rig's
  `matching_digest`, so that rig's calibrated stacks rebuild once. With it
  off, no key changes.
- **`CalibrationFrame::dark_subtracted`** records a master whose dark was
  removed before integration, as its `DARKSUB` header says.
  `FileCalibration` fills it from each frame's calibration state. A host
  that adopts external flat masters as dark-subtracted sets it for them.
- **`Rules::admits_sensor(light, frame)`** is the sensor test selection
  asks. With the setting on, a flat master with `dark_subtracted` may
  differ from the light in gain and offset. Raw flats, darks, bias and
  masters without `DARKSUB` still match exactly, which is what the stack's
  gate accepts. Selection, and a flat set supplied whole, use it.
- The pedestal session loader records the flat's `DARKSUB`, as
  `CalibrationMasters::from_fits_paths` does, so the gate can accept such a
  flat there too.

The C ABI's calibration JSON calls take the new key, and its schema gains
it and `dark_subtracted`. Python's `CalibrationRigRules` gains
`admits_sensor`, and its `CalibrationFrame` gains `dark_subtracted`
([#410](https://github.com/theatrus/seiza/pull/410)).

## Fixes

- Dark-flats pair with the nearest raw flat a light's selection takes.
  Before, they paired with its first flat, which could be an external
  master nearer the light at another exposure. The raw flats behind a
  master built from them were then integrated against the wrong flat
  darks, or none. A library that holds both raw flats and an external flat
  master may build its flat-dark master again.

## Package and output versions

The workspace packages (`seiza`, `seiza-cabi`, `seiza-cli`) and the Python
package are 0.48.1. `seiza-calibration` is 0.12.0. `seiza-stacking` 0.56.0
and `seiza-analysis` 0.4.0 carry the new dependency, which their public
types expose.

Stacking output stays 0.51.0 and stretch output stays 0.3.0. Existing
numerical summaries are unchanged; hosts keep their existing output-version
cache keys.
