# Seiza 0.55.0

Desktop and Rust hosts can now install ONNX Runtime through Seiza's shared
download API. The installer checks archive sizes and SHA-256 hashes, tries
PSF Guard's mirror before Microsoft's source, supports cancellation, and
repairs damaged installs. Verified installations work offline. Windows x64
receives the app-local VC++ dependencies too; no separate redistributable is
needed. Linux x64 and Apple Silicon are also supported.

Rust uses `seiza_download::OnnxRuntimeInstaller`; the C ABI exposes
`seiza_onnxruntime_installed_json` and `seiza_onnxruntime_install_json`.
Python exposes `installed_onnxruntime` and `install_onnxruntime`.
These calls install a CPU runtime without loading it or changing a host's
backend choice. Apps bundling DirectML can continue using their GPU runtime.
On Windows, Seiza also resolves the selected runtime's dependencies beside
its DLL, so hosts no longer need their own preload workaround.

CI runs actual model inference against the shared install on all three
platforms. Package downloads also use the verified mirror and now time out
stalled connections before trying the next source.

Forced aperture photometry samples local aperture pixels without copying
whole host image planes. Dependency updates are included. Stacking, stretch,
pipeline and noise-model output versions are unchanged from 0.54.0.
