# Seiza 0.44.0

Seiza 0.44.0 adds registered mosaic background matching and independent RGB
star stretching. Rust, C and Python share the same implementations; the CLI
also exposes the new star-layer operations.

## Mosaic integration

- Assign panel IDs to registered inputs to match additive sky planes through
  their overlaps, then taper remaining smooth differences at panel edges.
- Compare corresponding samples before clipping so shared stars and nebula
  structure cancel. Partial overlap cells and independent RGB channel masks
  retain their usable data; missing pixels remain missing. Clip residual
  differences before averaging so transient hits cannot spread into the
  smooth correction.
- Use the existing weighted rejection pass for full-resolution detail.
  Sample storage stays within 128 MiB by adapting the grid spacing.

Inputs must already share a pixel grid and photometric gain. Matching cannot
measure a sky gradient common to every panel, repair registration errors or
infer levels between panels without sampled shared coverage.

The six [Heart and Soul comparisons](../images/mosaic/README.md) use existing
panel integrations and a locked display transfer. Median residual seam steps
fall by 15.8% to 66.4%, depending on filter; these measurements include noise
and registration residuals.

## Independent RGB stars

- Extract a stars-only display layer from aligned linear original and
  starless RGB images, using one shared source scale and an independent
  stretch amount from 0 to 8.
- Screen that prepared stars layer over a display nebula with optional star
  reduction. This restoration does not stretch the layer again.

Star separation is supplied by the caller. Linear inputs retain their
physical units; the new tone operation produces a display layer.

## Package and output versions

The workspace packages (`seiza`, `seiza-cabi`, `seiza-cli`) and Python package
are 0.44.0. `seiza-stacking` and its output version are 0.51.0. Hosts should
include the stacking output version in cache identity.

`seiza-satellites` 0.22.2 and `seiza-parallax` 0.19.2 carry the compatible
Seiza dependency; their numerical behavior is unchanged. Stretch output is
unchanged. All 51 stacking summaries already present before the mosaic change
remain unchanged; four new mosaic cases protect the enabled behavior.
