# Fonts

The `seiza` binary embeds the Inter typeface through the `seiza-draw` crate,
for its sky map and parallax video labels; the font files and their details
are in [`seiza-draw/fonts`](../../seiza-draw/fonts/README.md). This copy of
[`LICENSE-Inter.txt`](LICENSE-Inter.txt), the SIL Open Font License 1.1, is
the one the Windows zip and MSI, the RPM and the deb ship beside the binary.
